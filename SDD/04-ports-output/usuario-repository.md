# UsuarioRepository

## Responsabilidad
Persistir y consultar la información de usuarios del sistema.

## Operaciones
- guardar(usuario)
- actualizar(usuario)
- buscarPorId(identificador)
- buscarPorCorreo(correo)
- existePorCorreo(correo)

## Casos de uso vinculados
- UC-01 Registrar usuario
- UC-02 Administrar usuario
