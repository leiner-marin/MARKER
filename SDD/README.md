# MARKER Software Design Documentation

The SDD documents the project from business requirements to implementation.

## Organization

- `01-business-rules/` — business rules
- `02-domain-model/` — domain entities, enums, and relationships
- `03-use-cases/` — application use cases
- `Domain/` — domain services, ports, value objects, and exceptions
- `05-architecture/` — architecture boundaries
- `06-data-model/` — persistence mapping
- `07-api/` — REST API contracts
- `08-testing/` — testing strategy
- `Business/Traceability.md` — requirement-to-implementation traceability
- `Completion-Roadmap.md` — implementation roadmap

All new documentation must use English terminology and remain synchronized with the implementation.
